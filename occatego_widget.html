ocCatego Widget - Enhanced Version

Descripción

Widget mejorado para asignar y administrar categorías usando el sistema de colores SCH con elevaciones y efectos de vidrio. Incluye:

  • Búsqueda en tiempo real de categorías
  • Drag & drop entre columnas (Si/Disponibles)
  • Botones de flecha para mover categorías individualmente
  • Botón de administración para CRUD de categorías
  • Diseño responsivo y compacto
  • Integración con sistema de colores SCH

Funcionalidades Implementadas

  • ✅ DOM-safe initialization: Constructor handles both loaded and loading states
  • ✅ Dynamic widget support: Use ocWidgetCategoManager.createWidget() for JS-created widgets
  • ✅ Memory leak prevention: Proper event listener cleanup with destroy() method
  • ✅ Singleton pattern: Safe to call constructor multiple times
  • ✅ Individual widget management: Track and manage each widget separately
  • ✅ Form integration: Automatic sync with linked select elements
  • ✅ Search auto-clear: Search clears after movements to show full state
  • ✅ Touch-friendly: 48px buttons for mobile interaction
  • ✅ Bulk operations: Move all categories with staggered animations

Usage Examples

// 1. Static HTML widgets (automatic)
<div class="ocWidget-catego">...</div>

// 2. Dynamic widget creation
const html = '<div class="ocWidget-catego">...</div>';
container.innerHTML = html;
ocWidgetCategoManager.createWidget('.ocWidget-catego');

// 3. Get/Set values programmatically
const widget = document.querySelector('.ocWidget-catego');
const values = window.ocWidgetManager.getValue(widget);
window.ocWidgetManager.setValue(widget, ['1', '3']);

// 4. Cleanup when removing widgets
window.ocWidgetManager.destroyWidget(widget);
// or cleanup everything:
window.ocWidgetManager.destroy();
