Actividades

Defina y gestione las actividades usadas en asignaciones de permisos. Use el Modo Edición para crear o modificar; luego asigne permisos desde Asignar Permisos.

🏠 Home 👤 Usuarios 🧩 Crear Rol 🔗 Asignar Permisos 📄 Reportes
Cómo usar esta página
  1. Active Modo Edición en la barra de acciones.
  2. Pulse Nueva Actividad o edite una existente desde la grilla.
  3. Complete Actividad y Descripción; guarde.
  4. Vaya a Asignar Permisos para asociarla a roles/usuarios.

Consejo: use el buscador/orden de columnas para encontrar actividades rápido.
