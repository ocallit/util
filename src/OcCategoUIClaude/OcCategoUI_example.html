Backend API Requirements

The widget expects your API endpoint to handle three actions:

  • add: Creates a new option (receives value and text)
  • update: Updates an existing option (receives id and text)
  • delete: Deletes an option (receives id)

Response format: {"success": true, "error": null, "data": {...}}
