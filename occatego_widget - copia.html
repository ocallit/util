ocCatego Widget - Enhanced Version

Descripción

Widget mejorado para asignar y administrar categorías usando el sistema de colores SCH con elevaciones y efectos de vidrio. Incluye:

  • Búsqueda en tiempo real de categorías
  • Drag & drop entre columnas (Si/Disponibles)
  • Botones de flecha para mover categorías individualmente
  • Botón de administración para CRUD de categorías
  • Diseño responsivo y compacto
  • Integración con sistema de colores SCH

Funcionalidades Implementadas

  • Búsqueda: El campo de búsqueda es lo más ancho posible y tiene botón de limpiar
  • Botones de flecha: Permiten mover categorías individualmente entre columnas
  • Drag handles: Preparado para implementar drag & drop con SortableJS
  • Colores SCH: Integración completa con el sistema de colores y elevaciones
  • Responsivo: Se adapta a pantallas pequeñas sin usar breakpoints específicos
  • Estados visuales: Hover, active y focus con transiciones suaves
  • Contadores: Muestra el número de categorías en cada columna
